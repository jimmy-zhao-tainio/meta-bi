# meta-bi

Sanctioned BI models and tools built on the `meta` workspace foundation.

The same modeled structure can be carried through the supported XML, SQL, and
C# workspace surfaces. The BI products make source contracts, transformations,
bindings, quality, pipelines, orchestration, and analytical targets explicit.

The public reference is generated from the MetaDocs suite in the sibling `meta` repository. Use `meta-<tool> help` for local command help and `meta-docs browse` for the modeled reference.
